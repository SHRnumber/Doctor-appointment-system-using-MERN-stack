# **🩺 Doctor Appointment System (MERN Stack)**  
*A modern, full-stack web application for booking and managing doctor appointments efficiently.*  

![image](https://github.com/user-attachments/assets/221e5f18-450b-4646-921a-3cf8756a3b5c)

---

## **✨ Features**  
✅ **User Authentication** (Patient & Doctor)  
✅ **Appointment Booking** with real-time availability  
✅ **Admin Dashboard** for managing users & appointments  
✅ **Responsive Design** (Works on mobile & desktop)  
✅ **Secure & Scalable** backend with JWT authentication  

---

## **🚀 Technologies Used**  
| **Tech** | **Description** |
|----------|----------------|
| **MongoDB** | NoSQL database for storing appointments, users, and doctors |
| **Express.js** | Backend framework for RESTful APIs |
| **React.js** | Frontend library for dynamic UI |
| **Node.js** | JavaScript runtime for server-side logic |
| **Redux / Context API** | State management |
| **JWT** | Secure user authentication |
| **Tailwind CSS / Material-UI** | Styling & responsive design |

## **📦 Installation & Setup**  
1. **Clone the repository**  
   ```bash
   git clone https://github.com/yourusername/doctor-appointment-mern.git
   cd doctor-appointment-mern
   ```

2. **Install dependencies (Frontend & Backend)**  
   ```bash
   cd client && npm install
   cd ../server && npm install
   ```

3. **Set up environment variables**  
   - Create a `.env` file in `/server` and add:  
     ```
     MONGO_URI=your_mongodb_connection_string
     JWT_SECRET=your_jwt_secret_key
     PORT=5000
     ```

4. **Run the application**  
   - **Backend:**  
     ```bash
     cd server && npm start
     ```
   - **Frontend:**  
     ```bash
     cd client && npm start
     ```
